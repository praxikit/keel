# praxikit

Practical kits for building with AI agents. Free, small, readable.

```
/plugin marketplace add praxikit/praxikit
/plugin install keel@praxikit
```

| Kit | Kind | What it does |
|---|---|---|
| [keel](kits/keel/) | plugin | Plan with a critique gate, build in phases with checks, route tasks to the cheapest capable model. |

A catalog page and per-kit versioning are in progress; see [`docs/plan/`](docs/plan/). MIT licence.
